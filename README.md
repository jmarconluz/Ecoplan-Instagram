# Ecoplan Instagram

Depósito das publicações do Instagram @ecoplanbarreiras, da Ecoplan Consultoria Ambiental.

Cada post tem uma pasta: `ano/mês/AAAA-MM-DD_tema/`.

- `arte.jpg`, `slide-1.jpg`, `reel.mp4` ou `story.jpg`: os arquivos do post. Post de foto real não tem arquivo aqui.
- `legenda.md`: situação, formato, legenda e fontes.

Este repositório é público, para que o Metricool abra os links das artes. Não guarde aqui dados de clientes, documentos internos ou contratos.
